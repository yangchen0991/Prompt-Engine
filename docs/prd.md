# 需求文档

## 1. 应用概述

### 1.1 应用名称
绘词引擎 V2 (Prompt Engine V2)

### 1.2 应用描述
绘词引擎是一个运行在浏览器中的可视化AI工作流设计平台，用户通过「节点连线」的方式编排多模态AI模型（文本、图片、视频），将提示词、图片、视频串联成自动化创作流水线。

**核心价值**：提示词不是终点，而是起点。用户不只是输入一行Prompt拿到一张图，而是把Prompt作为工作流的引擎节点，串联起「文字→图片→视频分析→分镜拆解→批量生成→本地保存」的完整创作链路。

**Slogan**：「提示词，即是画笔」

## 2. 用户与使用场景

### 2.1 目标用户
- 个人AI视觉创作者
- 视频内容制作人
- 提示词工程师
- 新手探索者

### 2.2 核心使用场景
- 角色设计：输入文本提示词生成角色图片
- 短片分镜：创建6镜分镜并批量生成视频
- 风格迁移：上传参考图片生成特定风格图片
- 多模型对比：同一提示词在不同模型间切换测试
- 批量创作：通过工作流节点串联实现自动化批量生成
- AI对话驱动：通过自然语言描述需求，自动生成画板节点和连接

## 4. 业务规则与逻辑

### 4.1 生成Pipeline状态机

**状态定义**：
- IDLE（空闲）：初始状态，等待用户触发生成
- SUBMITTING（提交中）：正在提交生成请求到API
- POLLING（轮询中）：异步任务轮询获取结果
- DONE（完成）：生成成功，结果已返回
- FAILED（失败）：生成失败或超时
- CANCELLED（取消）：用户主动取消任务

**状态流转规则**：
- IDLE → SUBMITTING：用户点击生成按钮
- SUBMITTING → POLLING：异步任务提交成功，开始轮询
- SUBMITTING → DONE：同步任务直接返回结果
- SUBMITTING → FAILED：提交失败
- POLLING → DONE：轮询成功获取结果
- POLLING → FAILED：轮询超时（300次×3秒）
- 任意状态 → CANCELLED：用户点击取消按钮

**同步生成流程**：
- 图片同步模式：IDLE → SUBMITTING → DONE（直接返回结果）

**异步生成流程**：
- 图片异步模式：IDLE → SUBMITTING → POLLING → DONE/FAILED
- 视频全异步：IDLE → SUBMITTING → POLLING → DONE/FAILED

**状态机管理**：
- 统一由UnifiedGenBar触发生成任务
- 状态变化时触发Toast通知
- 状态变化时更新节点UI（显示进度、缩略图、错误信息）
- 状态变化时更新全局状态栏进度显示

### 4.2 结果反馈系统

**Toast通知规则**：
- 生成开始：显示「生成任务已提交」
- 生成成功：显示「生成完成」+缩略图预览
- 生成失败：显示「生成失败：错误原因」
- 取消任务：显示「任务已取消」

**节点缩略图更新规则**：
- 生成完成后，节点内自动显示结果缩略图
- 缩略图尺寸：根据节点尺寸自适应
- 缩略图点击：打开大图预览

**底部状态栏更新规则**：
- 生成中：显示进度百分比和状态文本
- 生成完成：更新今日生成数量统计
- 生成失败：显示错误状态

### 4.3 摄影机参数注入规则

**参数捕获**：
- 手动捕获：用户点击「同步」按钮，捕获当前摄影机面板的所有调节参数
- 自动捕获：开启自动注入开关后，摄影机参数变化时实时捕获

**参数格式化**：
- 将捕获到的参数数据转换为描述性英文文本
- 默认格式示例：「Camera: 50mm lens, f/2.8, golden hour, rule of thirds」
- 用户可通过模板配置自定义输出格式、顺序和包含哪些参数
- 用户可勾选要注入的参数项（焦距/光圈/景别/构图/光照/色调/设备等）

**参数注入**：
- 将格式化后的参数文本附加到目标GenImageNode的提示词末尾
- 或根据用户配置的模板插入特定位置
- 注入范围：根据用户选择，仅注入选中节点或注入所有GenImageNode

**生成请求合并**：
- 用户点击生成按钮时，将原有提示词与摄影机参数文本合并
- 合并后的完整提示词提交给图像生成引擎

**视觉反馈**：
- GenImageNode节点界面显示小图标+文字，表明摄影机参数已注入且处于活动状态
- 右侧属性面板提示词Tab中的「注入预览区域」显示将要注入的参数文本

### 4.4 设备与镜头联动规则

**联动触发**：
- 用户在设备选择器中选择相机设备后，触发镜头选择器联动

**联动逻辑**：
- 根据选中设备的品牌和型号，匹配该设备兼容且常用的焦距与光圈范围
- 示例：选择Leica M11后，高亮显示28-75mm、f/1.4-f/5.6范围的镜头

**高亮显示规则**：
- 兼容镜头使用边框、背景色变化等视觉样式进行高亮提示
- 非兼容镜头保持默认样式，但仍可选择

**参数自动填充**：
- 用户选择镜头后，自动填充焦距、光圈参数到自定义参数编辑区

### 4.5 设备搜索规则

**搜索触发**：
- 用户在搜索框输入文本时，实时触发搜索

**搜索范围**：
- 品牌名称：如「Sony」「Canon」「Leica」
- 设备型号：如「A7」「M11」「5D」

**搜索结果显示**：
- 实时过滤设备列表，仅显示匹配结果
- 搜索框为空时，显示全部设备

**搜索匹配规则**：
- 不区分大小写
- 支持部分匹配

### 4.6 节点连接规则

- 防止自环：节点不能连接到自身
- 防止重复连线：两个节点之间不能有多条相同方向的连线
- 类型匹配：输出端口类型必须与输入端口类型匹配

### 4.7 结果处理规则

- 生成完成后，结果自动显示在节点预览区
- 同时更新历史记录面板
- 右侧属性面板「结果Tab」显示最近5个结果
- 每个结果提供快捷操作：变体、保存、预览、删除

### 4.8 撤销/重做规则

- 支持画布操作的撤销/重做：节点创建、删除、移动、连线
- 节点拖拽时暂停历史记录，拖拽结束后恢复
- 避免拖拽过程中每帧记录历史

### 4.9 Onboarding持久化规则

- 首次启动时检查localStorage中的`onboarding_completed`键
- 若键不存在或值为false，显示Onboarding引导
- 用户选择模板或关闭引导后，将`onboarding_completed`设置为true
- 后续启动不再显示引导

### 4.10 设计令牌应用规则

- 所有颜色、间距、字体、圆角、阴影统一使用CSS Custom Properties定义
- 组件样式引用令牌变量，不直接写死数值
- 令牌变量命名规范：`--token-category-name`（如`--color-primary`、`--spacing-md`）

### 4.11 AI画板自动生成规则

**需求解析流程**：
- 用户在对话界面输入需求描述
- 系统调用大语言模型解析需求文本
- 识别需求类型（如数据处理流程、图像生成流程、视频创作流程等）
- 提取关键要素（如输入类型、处理步骤、输出类型等）

**模型调度规则**：
- 根据需求类型选择合适的大语言模型
- 文本分析类需求：调用Chat模型
- 流程图生成类需求：调用专用流程设计模型
- 架构设计类需求：调用架构分析模型

**节点生成规则**：
- 模型返回节点配置方案（包含节点类型、参数、位置等）
- 系统根据配置方案在画布上自动创建节点
- 节点类型从预置节点库中选择（TextNode、GenImageNode、GenVideoNode、InputImageNode、CIDBoardNode）
- 节点参数根据需求自动填充

**连接生成规则**：
- 根据节点功能和数据流向自动建立连接
- 遵循节点连接规则（防止自环、防止重复连线、类型匹配）
- 连接线自动布局，避免交叉和重叠

**可视化反馈规则**：
- 生成过程中实时显示当前步骤（解析需求、选择模型、创建节点、建立连接）
- 节点创建时显示动画效果
- 连接建立时显示连线动画
- 生成完成后显示结果确认界面

**用户调整规则**：
- 生成完成后，用户可手动调整节点位置
- 用户可修改节点参数
- 用户可删除或新增连接
- 用户可保存调整后的画板结构

### 4.12 资产管理规则

**资产存储**：
- 图片、视频、音频资产存储生成结果文件
- 文本资产存储提示词内容
- 模型资产存储模型配置信息
- 预设资产存储摄影机参数预设
- 工作流资产存储画布节点和连接结构
- 角色资产存储CID Board角色参数
- 分镜资产存储6镜分镜描述和参数

**资产应用**：
- 工作流应用：将工作流结构加载到当前画布
- 角色应用：将角色参数应用到CID Board节点
- 分镜应用：将分镜描述加载到分镜面板

**资产删除**：
- 删除资产时同步删除关联文件和数据
- 删除前显示确认提示

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| API Key未配置 | 显示配置提示，引导用户打开设置弹窗 |
| 生成任务失败 | 节点显示失败状态，Toast通知错误信息 |
| 轮询超时（300次×3秒） | 标记为失败，Toast通知「生成超时，请稍后重试」 |
| 网络断开 | 状态栏显示未连接，禁用生成按钮，Toast通知「网络连接失败」 |
| 节点连接类型不匹配 | 阻止连线，Toast提示「端口类型不匹配」 |
| 画布节点数量过多（>100） | 性能降级模式，减少动画效果 |
| 上传文件格式不支持 | Toast提示「仅支持JPG、PNG、GIF、SVG格式」 |
| 历史记录为空 | 显示空状态提示「暂无生成记录」 |
| 未选中节点时打开属性面板 | 面板收起或显示引导创建节点提示 |
| localStorage不可用 | Onboarding每次启动都显示，Toast提示「浏览器存储不可用」 |
| 生成任务取消 | 状态机切换到CANCELLED，Toast通知「任务已取消」 |
| 摄影机参数注入开关关闭 | 生成时不附加摄影机参数文本，仅使用原有提示词 |
| 未勾选任何参数项 | 注入预览区域显示「未选择参数」，生成时不附加摄影机参数文本 |
| 摄影机参数文本过长 | 自动截断或提示用户精简参数选择 |
| 设备搜索无结果 | 显示「未找到匹配设备」提示 |
| 镜头数据库为空 | 显示「暂无镜头数据」提示 |
| 选择设备后无兼容镜头 | 镜头选择器显示全部镜头，无高亮提示 |
| AI画板生成需求描述不清晰 | 显示「需求描述不清晰，请补充更多细节」提示 |
| 大语言模型调用失败 | Toast通知「模型调用失败，请稍后重试」 |
| 节点配置方案无效 | Toast通知「生成方案无效，请重新描述需求」 |
| 自动生成节点数量超限（>50） | Toast提示「节点数量过多，建议简化需求」 |
| 自动生成连接出现循环依赖 | 自动检测并移除循环连接，Toast提示「已移除循环依赖连接」 |
| 资产管理库为空 | 显示空状态提示「暂无XX资产」 |
| 资产删除失败 | Toast通知「删除失败，请稍后重试」 |
| 资产导出失败 | Toast通知「导出失败，请检查浏览器权限」 |
| 工作流应用失败 | Toast通知「工作流加载失败，请检查数据完整性」 |

## 6. 验收标准

1. 用户打开应用，首次启动显示Onboarding引导
2. 用户选择「角色设计」模板，画布自动创建TextNode和GenImageNode并连线
3. 用户在TextNode输入提示词「一个赛博朋克风格的女性角色」
4. 用户选中GenImageNode，右侧属性面板打开，切换到摄影机Tab
5. 用户在设备搜索框输入「Sony」，设备列表实时过滤显示Sony品牌设备
6. 用户选择「Sony A7S III」设备，镜头选择器自动高亮显示兼容焦距与光圈范围的镜头
7. 用户选择「Sony FE 24-70mm f/2.8 GM」镜头，焦距、光圈参数自动填充到自定义参数编辑区
8. 用户开启摄影机参数自动注入开关，勾选焦距、光圈、色调参数
9. 用户点击「同步」按钮，注入预览区域显示格式化后的摄影机参数文本
10. 用户在统一生成栏选择模型「seedream」，点击生成按钮
11. GenImageNode显示生成中状态，底部状态栏显示进度，Toast通知「生成任务已提交」
12. 生成完成后，节点显示图片缩略图，节点界面显示摄影机参数已注入的视觉反馈，Toast通知「生成完成」
13. 用户点击节点，右侧属性面板显示结果Tab，确认生成结果符合摄影机参数要求
14. 用户打开AI画板生成对话界面，输入需求描述「创建一个图像风格迁移工作流，输入参考图片和文本描述，输出风格化图片」
15. 系统解析需求并显示识别结果（需求类型：图像生成流程，关键要素：参考图片输入、文本输入、图像输出）
16. 用户确认需求，系统自动在画布上创建InputImageNode、TextNode、GenImageNode三个节点
17. 系统自动建立连接：InputImageNode→GenImageNode、TextNode→GenImageNode
18. 生成完成后显示结果确认界面，用户确认画板结构正确
19. 用户点击底部资产管理库触发按钮，抽屉从底部向上滑出
20. 用户切换到「图片」类型Tab，查看已生成的图片资产缩略图
21. 用户点击某张图片资产，打开详情预览
22. 用户切换到「工作流」类型Tab，查看已保存的工作流资产
23. 用户点击某个工作流资产，选择「应用到画布」，画布加载该工作流结构
24. 用户切换到「角色」类型Tab，查看已创建的角色资产
25. 用户删除某个角色资产，系统显示确认提示，确认后删除成功并显示Toast通知
